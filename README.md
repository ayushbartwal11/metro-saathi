# 🚇 Delhi Metro Saathi

An interactive Delhi Metro route planner and map application built to provide optimal transit routes, fare calculations, and smooth station navigation.

## 🎯 Purpose
The purpose of **Delhi Metro Saathi** is to make commuting across Delhi-NCR effortless and transparent. Whether you are a daily commuter or a visitor, this application helps you find the fastest route, calculate exact travel times, know interchange stations, and check precise fare breakdowns instantly.

## ✨ Key Features & Advantages
* **Smart Route Planning (Dijkstra's Algorithm):** Instantly calculates the optimal path, minimizing travel time and interchange friction.
* **Interactive SVG Map:** Fully responsive visual map featuring smooth pan, zoom, and dynamic station highlighting for your active route.
* **Advanced Autocomplete Search:** Quick search supporting both official station names and major city landmarks with live line indicator dots.
* **Station Directory:** Comprehensive directory of all metro lines and stations with platform details and interchange points.
* **Distance & Fare Calculation:** Automatically computes total stops, approximate distance, and accurate ticket pricing.

## 🛠️ Tech Stack
* **HTML5** – Semantic structure and layout
* **CSS3** – Modern styling, custom variables, and responsive design
* **Vanilla JavaScript (ES6+)** – Route engine logic, graph algorithms, and interactive DOM manipulation
